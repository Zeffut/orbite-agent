# One Owner, one Agent, one Conversation

An installation serves exactly one Owner, runs exactly one Agent, and that Agent has exactly one Conversation. There are no user accounts, no list of chats and no team of named agents; long or parallel work goes to Sub-agents that report back and disappear. A single continuous Conversation is what makes the Agent feel like one colleague who remembers everything, and a single Owner keeps other people's mail and secrets out of the project's responsibility. Several named Agents may come after 1.0; multiple Owners are not planned.
