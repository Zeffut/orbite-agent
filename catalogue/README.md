# The catalogue of models

`models.json` holds what trying models out showed, by Provider and model. It is built into each release, and shown to an Owner choosing a model.

Every entry is the verdict of a real `orbite tryout MODEL`, with the day it was run: nothing here is an opinion or a guess. To add or refresh one, run the tryout against the Provider and copy what it measured. A model that is not here is tried out on the Owner's own Host when they choose it.

Consumption (how fast a model uses up a budget or a Subscription) is not in the catalogue: a tryout cannot measure it, since it depends on each Provider's prices and plans.
